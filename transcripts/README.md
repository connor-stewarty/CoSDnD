# Transcripts

Raw transcripts land here — either Vibe's own export (timestamped `.json`, one segment per line with `start`/`stop`/`text`) or a plain `.txt`/`.md` file, one per session. These are source material, not a deliverable — don't worry about cleaning them up or renaming Vibe's own filenames. The real recap writing happens in `../sessions/`, pulling out just what mattered.

If a transcript file gets huge, that's fine — this folder is just storage, it doesn't feed into the showcase site directly.

## Prep notes are useful too
A short hand-written note of what happened just *before* you hit record (like a top-level `before.md`) is genuinely useful — recordings often start mid-scene, and a couple of bullet points closing that gap makes a huge difference when writing the actual session recap later. Feel free to keep writing these; they don't need their own folder, just make sure whoever writes the recap knows to check for one.
