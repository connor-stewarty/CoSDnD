# Media

Maps, character art, battle-map photos, screenshots from VTT — anything visual worth keeping. Name files with the session number where relevant (e.g. `session-03-vallaki-map.jpg`) so it's easy to match media back to a recap.

If you want a piece of art or a map to appear on the showcase site, note the filename in the relevant `sessions/session-##.md` file so it doesn't get lost, and it can be added to `site/index.html` as a `data:` image or linked asset.
